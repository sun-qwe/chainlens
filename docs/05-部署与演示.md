# 部署与答辩演示指南

## 1. 一分钟启动

```bash
# 项目根目录（D:\桌面2\dsh-c）
python serve.py
```

浏览器打开 **http://127.0.0.1:8787/visualizer/**。无需 npm install、无需构建、无需联网。

若 8787 被占用：`python serve.py 8899`，并相应修改浏览器地址。

## 2. 演示脚本（约 6–8 分钟）

| 步骤 | 操作 | 讲解要点 |
|---|---|---|
| 1 | 打开总览（默认 campus-lab） | 授权信息、数据质量 100、6 个 KPI、阶段分布、严重度环图、关键路径摘要 |
| 2 | 点顶栏“链路图”，再点“关键路径” | 7 阶段分列；红色关键路径；hover/点击节点打开右侧详情；缩放、拖拽 |
| 3 | 点“时间线”，拖动底部进度或按空格播放 | 7 条阶段泳道；游标随播放移动；上方显示事件成功率与最长静默间隔 |
| 4 | 点“ATT&CK 矩阵” | 8/12 战术、16 技术；单元格计数；点击单元格过滤 |
| 5 | 点“发现与证据” | 严重度筛选、CVSS、证据数；切“证据库”看敏感打码；导出 CSV/JSON |
| 6 | 点“分析报告” → “打印 / PDF” | 九部分报告；浏览器打印对话框可另存 PDF |
| 7 | 顶栏“场景”切换 corp-ad / cloud-k8s | 数据规模变化；链路图默认可读字号；260 节点场景 |
| 8 | 点“导入”，拖入 `data/fixtures/invalid-demo.jsonl` | 1 个坏行、4 个错误、2 个警告仍可载入；体现容错 |
| 9 | 终端运行插件 demo/validate 与测试 | 确定性数据、独立校验、140 项测试 |

可选：打开 `#/about` 展示自检页与数据契约。

## 3. 安装 dsh-pentest 到 DSH（可选，不影响演示）

> 本项目**不修改**正在运行的 DSH 配置；以下为进阶步骤，建议在独立配置副本中操作。

1. 将 `dsh-pentest/` 复制到 `$DSH_HOME/local-plugins/dsh-pentest`（Windows 通常为 `C:\Users\<用户>\.dsh\local-plugins\`）。
2. 在目标 profile 的 `cordis.patch.yml` 中追加：

   ```yaml
   - insert:
       - id: dsh-pentest
         name: dsh-pentest
   ```

3. 重启对应 DSH 会话/宿主。插件会尝试通过动态 import 注册 4 个工具；宿主不提供 `ctx.tools` 时自动降级，不影响加载。
4. 数据默认写入 `$DSH_HOME/pentest/engagements/<id>/chain.jsonl`，可用 `DSH_PENTEST_DATA_DIR` 覆盖。
5. 安装前请阅读 [docs/插件说明.md](插件说明.md) 的安全边界与已知限制。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面 404 或空白 | 确认在**项目根目录**执行 `python serve.py`，地址为 `/visualizer/` |
| 提示“未检测到数据集” | `data/manifest.json` 缺失或路径不对；页面会载入内置 fallback，可手动导入 JSONL |
| 导入后刷新消失 | 导入数据仅保存在内存，这是设计行为；需要持久化请先下载导出 |
| 测试报 `spawn EPERM` | 受限沙箱禁止 Node 测试子进程 IPC，使用 `--test-isolation=none` |
| 链路图字太小 | 点“适配”看全貌；或点击节点/筛选聚焦；默认缩放已保证 ≥0.7 |
| 报告打印页眉/侧栏 | 打印样式会自动隐藏控制台外壳，仅保留报告内容；在打印预览确认 |
| 端口被占用 | `python serve.py 8899` |
