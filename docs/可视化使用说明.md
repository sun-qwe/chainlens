# ChainLens 可视化使用说明

> 面向 `dsh-pentest` 探索链路数据的零依赖可视化分析工具。本文档对应当前 `visualizer/` 实现（v1.0.0）。
> 项目根目录：`D:\桌面2\dsh-c`；数据契约见 `docs/00-设计规格.md` 与 `data/schema/chain.schema.json`。

## 1. 启动

在项目根目录执行：

```powershell
python serve.py
```

然后访问：

```
http://127.0.0.1:8787/visualizer/
```

`serve.py` 以项目根目录为静态根，页面通过同源请求读取 `../data/manifest.json` 与 `../data/scenarios/*.jsonl`，不访问任何外部网络。直接双击 `index.html`（`file://`）会因浏览器同源策略无法读取数据文件，请务必使用本地服务。

页面加载流程：

1. 读取 `../data/manifest.json`，选择场景（`?scenario=` 指定或默认第一个）；
2. 读取场景 JSONL，经 `parser.js` 解析、归一化与语义校验；
3. 失败（文件缺失、坏数据、超时）时自动回退到 `js/fallback-data.js` 内置演示数据，并在顶栏下方显示导入提示；
4. 首屏渲染完成后解析 `window.__chainlensReady`，可用 `await window.__chainlensReady` 等待。

## 2. 界面结构

- **顶栏**：Logo、场景选择器（MANIFEST / FALLBACK / IMPORT / DEV 徽标）、六个视图 Tab、导入、导出菜单、帮助。
- **左侧筛选栏**：搜索、阶段、节点类型、严重度、事件结果、数据质量卡、快捷键提示。
- **中央视图**：总览 / 链路图 / 时间线 / ATT&CK 矩阵 / 发现与证据 / 分析报告。
- **右侧详情抽屉**：点击节点、事件、证据、关系后滑出；`Esc` 关闭。
- **底部回放条**（链路图 / 时间线）：播放/暂停、上一/下一事件、进度滑杆、当前事件摘要、速度 0.5×/1×/2×/4×、时间戳。
- **导入弹窗**：拖拽或选择 `.jsonl/.json`，展示校验统计与错误/警告明细；数据只在浏览器内存中使用。
- **#/about**：项目说明、算法摘要、快捷键、自检与 bench 入口。

## 3. 六个视图

### 3.1 总览 `#/overview`

- Hero：场景名称、模式、授权依据、目标范围、操作者/团队、测试窗口、数据质量分。
- 6 个 KPI：节点、关系、事件、漏洞/发现、证据、关键路径风险，均可点击跳转。
- 图表：阶段分布（节点/事件）、严重度环图、事件时间密度（10 分钟桶）、节点类型 Top、ATT&CK 覆盖。
- 链路摘要：关键路径节点串（点击跳转链路图并聚焦）、Top 5 风险节点、最近 8 条事件。

### 3.2 链路图 `#/graph`

- 7 个阶段列，列标题显示阶段名、节点数与子列数；单阶段节点过多时自动在列内换行（子列），以控制画布纵横比。
- 节点卡片：类型图标 + 标签 + 类型/阶段 + 风险条；边：按 relation 着色的贝塞尔曲线 + 箭头，`evidences/belongs_to/routes_to` 为虚线。
- 交互：
  - 滚轮缩放（0.3–2.5×）、拖拽空白平移、拖拽节点临时固定（双击释放）、双击背景无副作用；
  - 工具栏：分层/力导向切换、缩放、适配屏幕、重置、关键路径高亮；
  - 搜索/筛选后重排（动画）；
  - 选中节点时高亮 1 跳邻居，其余淡化；
  - 关键路径红色流动虚线；
  - 回放时按 cursor 渐进显示节点/边，当前事件节点脉冲；
  - 点击节点/边打开右侧详情抽屉。
- **默认视图策略**：优先保证可读字号（默认缩放不低于 0.7），内容超出画布时允许拖拽平移；“适配屏幕”按钮可将完整图形缩放到画布内。深链 `zoom` 可固定初始缩放，`fit=1` 等价于点击“适配屏幕”。

### 3.3 时间线 `#/timeline`

- 上方统计：事件跨度、成功率、最长静默间隔、各阶段耗时（含迷你条形图）。
- 7 条阶段泳道，事件按时间落点，颜色按 result，风险高/关键动作放大标记；未来事件在回放中淡化。
- 滚轮缩放时间范围、拖拽平移、双击重置；点击事件：定位回放游标并打开详情。
- 与链路图共享 `cursor` 状态。

### 3.4 ATT&CK 矩阵 `#/attack`

- tactic 为列（全部 12 个，未使用的列淡化），technique 为行（只显示数据中出现的），单元格颜色/数字表示事件计数。
- 顶部覆盖指标：战术覆盖 x/12、技术数、映射事件数、映射记录数。
- 点击单元格筛选下方命中事件列表；再次点击或“清除选择”恢复。事件行可点击打开详情。

### 3.5 发现与证据 `#/findings`

- 汇总条：严重/高危/中低危计数、已确认比例、证据覆盖率。
- 「风险发现」表格：严重度、标题、CVSS、资产、阶段、状态、证据数；表头可排序，侧栏搜索/严重度/阶段筛选生效。
- 「证据库」表格：类型、标题、关联节点、时间、敏感标记；`sensitive:true` 的证据不会展示摘要。
- 支持导出发现 CSV、证据 JSON（顶部按钮或“导出”菜单）。

### 3.6 分析报告 `#/report`

- 基于当前数据自动生成的文档式报告：报告信息、执行摘要、范围与授权、链路指标、阶段推进、关键路径、Top 发现（含建议）、ATT&CK 覆盖、证据清单、数据质量说明。
- 按钮：打印/另存 PDF（`window.print()`，A4 打印样式）、复制 Markdown、导出 JSON。
- 报告内容全部由真实数据计算，不使用占位符。

## 4. 深链（用于截图与自动测试）

格式：`#/<view>?参数`。页面初次加载与 `hashchange` 都会应用参数；参数缺失时恢复默认。

| 参数 | 示例 | 说明 |
|---|---|---|
| `scenario` | `campus-lab` | 场景 id；与 `data/manifest.json` 对应 |
| `cursor` | `15` | 回放事件游标（0–事件总数）；省略表示全部显示 |
| `critical` | `1` | 关键路径高亮 |
| `focus` | `vuln-007` | 聚焦节点 id，同时打开详情抽屉；节点会强制补回可见集合 |
| `filter` | `stage:initial_access,type:vulnerability` | 阶段/类型/结果/关系筛选，逗号分隔；多值用 `\|` |
| `severity` | `high,critical` | 严重度筛选 |
| `q` | `导出` | 搜索关键词 |
| `tab` | `findings` / `evidence` | 发现与证据视图 Tab |
| `zoom` | `0.8` | 链路图初始缩放（0.3–2.5） |
| `fit` | `1` | 链路图初始执行“适配屏幕” |
| `tactic` / `technique` | `TA0001` / `T1190` | ATT&CK 视图预选单元格 |
| `data` | `../data/fixtures/mini.jsonl` | 开发/联调：直接加载指定 JSONL（同源相对路径） |

额外调试参数：URL 查询串（不是 hash）中加 `?offline=1` 可强制使用内置 fallback 数据，用于验证“未检测到数据集”的导入提示；`?selftest=1` 会在控制台输出版本与数据统计自检结果。

常用截图深链（1600×1000 或 1366×768）：

```text
#/overview?scenario=campus-lab
#/graph?scenario=campus-lab&critical=1&cursor=15&zoom=0.8
#/graph?scenario=campus-lab&focus=vuln-002&zoom=1&critical=1
#/timeline?scenario=campus-lab&cursor=15
#/attack?scenario=campus-lab
#/findings?scenario=campus-lab&severity=high,critical
#/findings?scenario=campus-lab&tab=evidence
#/report?scenario=campus-lab
#/about
```

说明：

- 链路图缩放/适配后会把 `zoom` / `fit` 写回 URL（仅在链路图视图输出），因此截图链接可复现；
- `filter` 未命中任何节点时会显示空态；`focus` 节点即使不满足筛选，也会被补回并高亮；
- 深链参数非法时会被忽略或回退默认值，不会报错。

## 5. 筛选、搜索与回放

- **搜索**：匹配节点 id/label/类型/阶段/props、事件 action/summary/detail、证据标题（敏感证据摘要不参与搜索）、发现标题/CVE/资产。
- **筛选**：阶段、节点类型、严重度、事件结果；关系筛选可通过深链 `filter=relation:...` 使用。
- **回放**：链式事件按时间排序；`cursor` 表示已展示事件数。播放节奏由事件间隔归一化映射到 350–1400ms，再按速度倍率缩短。切换视图保留 cursor；切换场景会重置。
- **详情抽屉**：节点（属性/ATT&CK/关联证据/相关事件/关系）、事件（时间/动作/结果/详情/关联节点/证据）、关系、证据（敏感打码）、批注。

## 6. 快捷键

| 按键 | 功能 |
|---|---|
| `1`–`6` | 切换六个视图 |
| `/` | 聚焦搜索框 |
| `Esc` | 关闭导入弹窗 / 导出菜单 / 详情抽屉 |
| `Space` | 播放/暂停（链路图、时间线） |
| `←` / `→` | 上一 / 下一事件 |
| `F` | 链路图适配屏幕 |
| `C` | 关键路径高亮 |
| `?` | 打开 #/about |

## 7. 导入与导出

- **导入**：顶栏“导入”或数据提示条按钮，支持拖拽/选择 `.jsonl` 或 JSON 数组；解析后显示有效记录、节点、关系、事件、证据、坏行、错误、警告数量，以及错误/警告明细。存在阻断性错误（空文件、缺 meta、无节点、非法 JSON）时禁用“载入”；可载入时自动切换为“导入”场景。导入数据只存在内存中，刷新后恢复默认数据。
- **导出**（均为 Blob 本地下载，无网络请求）：
  - 发现 CSV（UTF-8 BOM，可直接 Excel 打开）；
  - 证据 JSON（敏感 evidence 的 summary 导出为 `[REDACTED]`）；
  - 报告 JSON（与报告页内容一致的结构化模型）；
  - 复制当前深链（写入剪贴板）。

## 8. 自检与性能接口

在控制台可访问：

```js
window.ChainLens              // { app, data, analytics, layout, parser, replay, bench, actions, report }
window.ChainLens.data         // 当前归一化链路 { meta, nodes, edges, events, evidences, notes, warnings, errors, stats }
window.ChainLens.analytics    // 指标函数（criticalPath / dataQuality / attackCoverage / ...）
window.ChainLens.layout       // layoutLayered / layoutForce / layoutGraph
await window.__chainlensReady // 首屏渲染完成
window.__chainlensState       // 当前状态快照（视图、场景、cursor、筛选、焦点、错误数）
window.__chainlensErrors      // 页面运行时错误收集（正常应为空数组）
```

性能接口（无 UI 副作用、可重复调用）：

```js
await window.ChainLens.bench('campus-lab');
// => { scenarioId, records, nodes, edges, events, fetchMs, parseMs,
//      layoutMs, renderMs, firstScreenMs, renderedNodes, memory, at }
```

当前开发机（headless Chrome，1600×1000）实测参考：

| 场景 | 节点 | 解析 | 布局 | 渲染 | 合计 |
|---|---|---|---|---|---|
| campus-lab | 66 | ~0.8ms | ~2.5ms | ~4.7ms | ~8ms |
| corp-ad | 180 | ~1.6ms | ~5.3ms | ~14.6ms | ~22ms |
| cloud-k8s | 260 | ~2.8–4.0ms | ~3.4–5.2ms | ~11–12ms | ~17–25ms |

注：不同机器/浏览器会有差异；报告页首屏还包含外部资源加载，`window.__chainlensState.firstScreenMs` 为从页面脚本启动到首屏渲染完成的耗时（通常 < 200ms）。

自检入口：

```text
http://127.0.0.1:8787/visualizer/?selftest=1
```

会在控制台输出当前场景统计与首屏耗时，并写入 `window.__chainlensSelftest`。#/about 页面的“运行自检”按钮也会执行同样检查（解析、布局完整性、关键路径、ATT&CK、数据质量、全局接口）。

## 9. 数据质量与保险丝

- 解析规则：JSONL（忽略空行）或 JSON 数组；首行必须为 `meta`；`seq` 严格递增；`ts` 非递减；节点/关系/事件/证据/批注 id 唯一；`from/to` 引用完整；敏感字段检测（`password/token/cookie/secret/key` 等）递归扫描 props。
- 坏行跳过并计入 `errors/warnings`；单文件致命错误（空、缺 meta、无节点、非法 JSON 根）拒绝加载并回退内置数据。
- 质量分：`max(0, 100 - 8×errors - 2×warnings)`，在顶栏、总览 Hero、侧栏显示；报告页列出错误/警告明细。
- 安全：`sensitive:true` 的证据在前端默认打码，只显示标题与“已脱敏”；敏感字段值统一替换为 `[REDACTED]` 展示。工具只展示数据，无任何扫描/攻击能力。

## 10. 前端分析算法摘要（对应论文）

1. **解析与校验**：JSONL/JSON 解析 → 记录级语义校验 → 引用完整性/时间单调性/敏感字段检测 → 错误/警告聚合 → 数据质量分。
2. **指标**：`nodeTypeCounts`、`stageCounts`、`severityCounts`、`durationMs`、`stageStats`、`successRate`、`longestSilence`、`attackCoverage`、`evidenceCoverage`、`riskScore`（severity 权重 × confidence）、`timeBuckets`。
3. **关键路径**：仅使用阶段前向边（同一阶段按 `ts, id` 排序视为前向），节点权重 `1 + risk`，在 DAG 上做 DP 最长路径；无前向边时回退到最高风险节点。
4. **布局**：
   - 分层布局：7 阶段列 → 阶段内按节点数量自动分子列 → 重心法排序（前进/后退交替 ≥4 轮）→ 同层一维轻量力松弛（弹簧 + 最小间距 + 去漂移）；
   - 力导向布局：Fruchterman-Reingold 300 次迭代，固定种子 PRNG，初始位置来自分层布局，确定性可复现。
5. **回放**：事件按时间排序，`visibleState(cursor)` 计算可见节点/边与当前事件；节奏按事件间隔归一化（350–1400ms / 速度）。
6. **筛选**：节点/关系/事件/证据分别计算匹配集合，关系筛选时收敛到相关节点；敏感证据摘要不参与搜索。

## 13. 已知限制

- 浏览器需支持 ES Modules 与 SVG（现代 Chrome / Edge；IE 不支持）。
- 链路图默认可读优先，超大场景初始只显示局部，需拖拽平移；可点击“适配”查看全貌。
- 导入数据不写磁盘，刷新后恢复默认场景；需要留存时请先“导出”。
- ATT&CK 矩阵在 1366 宽度下需要横向滚动查看后 2–3 列。
- 内置 fallback 数据仅用于离线演示；正式论文截图请使用 `data/manifest.json` 中的三个场景。
