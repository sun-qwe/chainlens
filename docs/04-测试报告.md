## 2. 测试方法

1. **契约与语义测试**：`data/schema/chain.schema.json` + 独立检查器 `tools/chain-check.mjs` + 前端解析器，验证三场景与非法样例。
2. **单元测试**：插件 8 个测试文件、前端 6 个测试文件，覆盖 schema、脱敏、scope 守卫、存储、仿真、解析、分析、布局、回放、路由、过滤。
3. **端到端测试**：`tools/e2e-check.mjs` 通过无头 Chrome 驱动真实页面，覆盖三场景、六视图、深链、1366×768、坏数据与关键路径算法，共 31 项检查。
4. **性能实验**：`tools/bench.mjs` 调用 `window.ChainLens.bench()`，三场景各采样 3 次取中位数，记录 fetch/parse/layout/render/首屏/内存。
5. **可用性/兼容性**：1366×768 布局、键盘快捷键、控制台异常、深链复现、导入容错。

## 6. 性能实验结果

1600×1000，headless Chrome 157，3 次采样中位数：

| 场景 | 节点/关系/记录 | fetch | parse | layout | render | 管线合计 | 页面首屏 | JS 堆 |
|---|---|---|---|---|---|---|---|---|
| campus-lab | 66 / 51 / 150 | 0.0 ms | 1.0 ms | 2.3 ms | 4.3 ms | 7.7 ms | 72 ms | 2.69 MB |
| corp-ad | 180 / 150 / 450 | 0.1 ms | 3.0 ms | 5.3 ms | 11.5 ms | 19.2 ms | 101 ms | 3.76 MB |
| cloud-k8s | 260 / 320 / 900 | 0.1 ms | 3.6 ms | 5.3 ms | 14.5 ms | 23.3 ms | 80 ms | 5.23 MB |

- 与设计目标（260 节点/320 边首屏 < 1 s）对照：管线 23.3 ms、页面首屏 80 ms，均显著低于目标。
- 增长趋势：节点数约 3.9 倍时管线耗时约 3.0 倍，近似线性；渲染是主要开销（260 节点时 14.5/23.3 ≈ 62%）。
- 复跑命令：`node tools/bench.mjs`；原始数据：`docs/bench-results.json`；图表：`thesis/figures/fig-6-1-perf.png`、`fig-6-2-scale.png`。

## 7. 可用性与兼容性

- 1366×768：总览、链路图、时间线、ATT&CK、发现、报告均无横向溢出；`scrollWidth = innerWidth = 1366`。
- 浏览器控制台：三场景六视图 `errors: []`、`consoleErrors: []`。
- 深链：`scenario / cursor / critical / focus / zoom / fit / filter / severity / tab` 均生效；游标越界自动夹取。
- 键盘：`1–6` 切换视图、`/` 搜索、`Esc` 关闭抽屉、`Space` 播放、`←/→` 步进、`F` 适配、`C` 关键路径、`?` 帮助。
- 导入容错：非法 JSONL 有明确错误提示与载入按钮状态；合法 JSONL 可载入为“导入”场景并切回 manifest 场景。

## 8. 结论与已知问题

**结论**：契约、单元测试、端到端、容错与性能五类测试全部通过；三场景数据一致可复现；性能显著优于设计目标；系统可在 1366×768 投影环境稳定演示。

**已知问题（不阻塞交付）**：

1. 无头 Chrome 无剪贴板权限时，“复制 Markdown/深链”会提示失败；普通浏览器可用。
2. 报告 A4 打印样式已实现，但未在 headless 环境实测打印对话框输出。
3. ATT&CK 12 列矩阵在 1366 宽度下需横向滚动。
4. 大场景链路图默认优先可读字号，全貌需点“适配”或筛选。
5. 受限沙箱下 Node 测试需 `--test-isolation=none`；普通终端可直接 `node --test`。
