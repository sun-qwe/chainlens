阶段化链路示例（关键路径以红色标出）

动态规划求解

约束
仅使用前向边：stage(from) < stage(to)；
同阶段按时间先后；检测并剔除回边。
状态转移
dp(v) = w(v) + maxu∈pred(v) dp(u)

w(v) = 1 + risk(v)
答案
终结点集合 { v | outdeg(v) = 0 } 中 dp 最大者，沿前驱回溯得到节点序列；复杂度 O(|V|+|E|)。
示例（左图红线）
host(5.5) → 弱口令(9.1) → 教师账号(8.0)
→ 会话(8.5) → 越权(6.8) → 数据(8.0)
→ 风险发现(9.0)
关键路径回答"哪条链路贡献了最大风险"；
无前向边时回退为最大风险单节点，
保证异常数据下仍有可解释输出。
阶段为列·红色为关键路径·权重同时考虑风险与链路长度
